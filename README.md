# TheoTown Translation

## Upcoming changes to translation contributions

We are changing how translations for TheoTown are maintained. Going forward, translations will be managed internally rather than through community contributions on GitHub.

As part of this transition, we plan to discontinue accepting translation pull requests through this repository. We kindly ask contributors to refrain from starting new large-scale translation projects in the meantime.

Translation feedback will still be welcome! If you notice an incorrect or unnatural translation in the game, you can send us a specific correction suggestion via info@theotown.com. Please include the language, the affected text, and your suggested improvement.

We would like to thank everyone who has contributed translations over the years. Your efforts have helped make TheoTown accessible to players around the world, and we greatly appreciate your support.

We will update this repository once the transition is complete.
